# Course Repo
## CS 3100 - Data Structures and Algorithms 



This repository contains **in-class example code** written during lecture for
**CS 3100 / CS 5100 – Data Structures and Algorithms**.

The purpose of this repository is to give you **reference material** for concepts demonstrated live in class.

## Course Guide

The **Course Guide** contains the full schedule with assignments: [course_guide.md](course_guide.md)

---

## What This Repository Is

- Code written **during lecture**
- Small, focused examples illustrating:
  - C++ syntax and structure
  - Parameter passing (value, reference, pointer)
  - Arrays and loops
  - Classes and object organization
  - Dynamic memory
  - Linked lists and data structure mechanics
- A place to **review ideas**, not finished solutions

You are encouraged to:

- Pull this repo regularly
- Open the examples in CLion
- Compile, run, and experiment with the code
- Modify examples locally to test your understanding

---

## What This Repository Is *Not*

- ❌ **Not starter code** for assignments or projects
- ❌ **Not complete solutions**
- ❌ **Not guaranteed to be production-quality**
- ❌ **Not a substitute for doing the assignments yourself**

Some examples may:

- Be incomplete
- Skip edge cases
- Contain debug output
- Favor clarity over robustness

This is intentional.
